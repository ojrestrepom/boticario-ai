# Instrucciones para agentes

## Formato de Markdown

- No cortes las líneas a mano. Escribe cada párrafo y cada elemento de lista en una sola línea y deja que el editor haga el ajuste de línea.
- La regla aplica a todo Markdown nuevo o editado: `README.md`, `docs/`, `openspec/specs/` y los artefactos de cambios de OpenSpec (propuesta, diseño, tareas, specs delta e informes de QA).
- No aplica al contenido de los bloques de código ni a las tablas, que conservan su formato.
- No reescribas los cambios archivados en `openspec/changes/archive/` para ajustarlos a esta regla: son registros históricos y se conservan como están.
