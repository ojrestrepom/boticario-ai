Nota: cada grupo es un commit. El orquestador hace el commit al aceptar el grupo. Todo `git push`, la creación de ramas remotas y cualquier acción en GitHub (`gh`) requieren aprobación del usuario y las ejecuta el orquestador; las tareas lo marcan con «[orquestador]».
