# Tasks

Nota: las tareas 1 a 6 y 11 usan las herramientas de `tools/catalog-seed/` (Python, solo para el desarrollador); las tareas 7 y 8 son Rust y Docker. Las pruebas de Python se ejecutan con `python3 -I -m unittest discover -s tools/catalog-seed/tests` desde la raíz y las de Rust con `mise exec -- cargo test --workspace --locked` desde `backend/`. Las pruebas automáticas no usan la red: trabajan con fixtures pequeños. Cada grupo deja sus pruebas y su documentación (el `README.md` de `tools/catalog-seed/` se va completando); el grupo 9 documenta el flujo completo y el modelo de datos. Los Markdown nuevos o editados cumplen la regla de una línea por párrafo y por elemento de lista. Las descargas reales (tareas 1.x y 3.x) necesitan red y se ejecutan a mano; la caché queda en `data/.cache/`. Ninguna tarea hace `push` a `main`, porque despliega (véase el diseño, plan de migración). La tarea 11 requiere la decisión del usuario sobre el modo de ejecución.
