Orden de nombres comunes (API-03): el orden es binario (UTF-8), no alfabetico: mayusculas antes que minusculas y letras acentuadas al final.
El escenario 'Nombre para mostrar primero' del delta de catalog-api da como resultado esperado «Lavanda», «Árnica», «Espliego» (alfabetico).
Con el orden binario, «Espliego» (E) iria antes que «Árnica» (Á).
