# Tasks

Nota: este cambio depende de que `consolidate-catalog-seed` esté implementado (al menos sus tareas 1 a 7: semilla provisional de la corrida de control y build desde la semilla; la semilla completa es la tarea 11 de ese cambio). Las pruebas de Rust se ejecutan con `mise exec -- cargo test --workspace --locked` desde `backend/`; las de la app con `flutter test test/` desde `app/`. Las pruebas automáticas no usan la red. Cada grupo deja sus pruebas y su documentación. Los Markdown nuevos o editados cumplen la regla de una línea por párrafo y por elemento de lista. Ninguna tarea hace `push` a `main`, porque despliega (véase el diseño, plan de migración).
